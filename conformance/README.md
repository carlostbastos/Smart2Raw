# Smart2Raw conformance fixtures

This directory contains canonical `.s2r` fixtures used to prove that the C core and ecosystem ports agree on the portable file format.

The fixtures are generated by `conformance/scripts/generate_fixtures.py` using the pure-Python port, then read by the C CLI, Go port, JavaScript port, and Python port.

## Fixtures

- `unsigned_u8.s2r`
- `unsigned_u16.s2r`
- `unsigned_u32.s2r`
- `signed_i8.s2r`
- `signed_i16.s2r`
- `corrupted_crc.s2r`
- `manifest.json`

## Regenerate

```sh
python3 conformance/scripts/generate_fixtures.py
```

## Why this matters

The format is not an implementation accident. These fixtures make `.s2r` a portable contract: multiple language implementations must parse the same bytes, agree on class, count, sign, sum, and reject CRC corruption.
