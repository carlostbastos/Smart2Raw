3 · o mesmo dado em cada formato

representaçãobytes× int64  o que é

O Smart2Raw classifica por amplitude, e a classe mais larga é o int64 de entrada — por isso ele não tem regime onde expande. Os especialistas têm: o dicionário guarda um dicionário do tamanho do dado quando a cardinalidade é alta, o RLE guarda uma corrida por valor quando o dado não está ordenado, e o bitmap só existe com dois valores distintos. Cada linha vermelha acima é um formato que ficou maior que a entrada.

Qual representação é a menor e qual responde mais rápido são perguntas diferentes, então todas as disponíveis são medidas, inclusive quando perdem. Em coluna pequena que cabe no cache do processador o ganho de espaço não vira ganho de tempo — aumente o número de elementos e a diferença aparece.

5 · o tamanho de bloco é classificado, não chutado

blocobytes previstos× melhor 

s2r_blocked_plan() precifica todos os candidatos a partir de uma única passagem sobre o dado, com uma fusão em árvore dos gcds que é exata por construção. A linha marcada é a que s2r_blocked_choose_block() escolheu.

6 · o arquivo

Esses bytes foram escritos pelo s2r_blocked_save() de verdade, não por um gerador de exemplo: a página só trocou o disco por um bloco de memória. O arquivo foi reaberto com s2r_blocked_load(), o CRC conferido e cada valor comparado com o original antes de este botão aparecer. Ele abre em qualquer build 3.5.0 da biblioteca — e, se a coluna não tiver passo comum, é byte a byte o arquivo que a 3.4.0 escrevia.

7 · o que esta página prova, e o que não prova

Prova: que a classificação, a fatoração afim, o planejador, os predicados e o serializador são o código de verdade — o smart2raw.h compilado para wasm32, sem reimplementação em JavaScript — e que naquilo que dá para conferir contra um laço ingênuo eles conferem, no seu dado, no seu navegador. Prova também o limite superior: nenhuma forma do Smart2Raw excedeu a linha de base int64 em nenhuma coluna que você colocar aqui, porque a classe mais larga é essa linha de base.

Não prova: que o Smart2Raw seja sempre o menor. Onde a cardinalidade é baixa mas a amplitude é grande — poucos valores distintos espalhados —, o dicionário com código de 3 ou 4 bits ganha em espaço, e a tabela acima mostra isso sem maquiagem. A menor classe nativa tem 8 bits, e essa ausência é a decisão de projeto que compra o resto: os bytes guardados são inteiros nativos, então não existe passo de decodificação, materialização nem dicionário na memória para consultar.

Também não prova desempenho de servidor: um navegador mede o que um navegador mede. Para número comparável, o repositório traz benchmarks/ em C, com asserção antes de cada linha impressa.
